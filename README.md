# InspeCampo

App Flutter de inspeção de campo - desafio técnico para vaga de Desenvolvedor Mobile Flutter.

> 🚧 Em desenvolvimento — este README será completado ao longo do projeto.

## Sobre o projeto

Mini app para técnicos registrarem inspeções em ordens de serviço,
com suporte a operação offline e sincronização posterior com uma API mock.

## Estrutura do repositório

- `mock-api/` — servidor mock da API 
- `inspecao_campo/` — aplicativo Flutter
